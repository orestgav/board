> [!info] Текст для гравців — лише поле `Гравцям:`
> Гравцям призначено **виключно** те, що написано в полі `Гравцям:`. Усе інше — гачки, прогрес, «не визначено», рядки з 🔒 — лишається тут.
> Якщо у квеста немає поля `Гравцям:`, гравцям він не показується. Саме так і має бути для того, про що партія ще не знає.
> Групи (`## Основне` / `## Другорядне` / `## Виконано`) визначають порядок.

```

  - Прогрес: що вже зроблено
  - 🔒 те, чого гравці не знають — гравцям не показується
  - Гравцям: текст для гравців; без цього поля квест їм не показується
```
